Write the agent-specific bits once; get checkpointed memory, sandboxing, approval gates, and telemetry for free.</p> </div> <div class="card"> <h3>Compiled LangGraph ReAct Agent</h3> <p>The runtime graph. Tool calls route through an <code>execute_tools</code> gate; failed tools return a <code>ToolMessage</code> the model can reason about and recover from, never a raw exception that crashes the run.</p> </div> <div class="card gate"> <h3>safe_path() — sandbox wall</h3> <p>Rejects path traversal and symlink escape within a sandbox root that is bound once, at tool-construction time, by whoever builds the <code>AgentSpec</code> — never accepted as a model-supplied argument. <code>_assert_no_model_controlled_sandbox()</code> exists specifically to guard the regression (ADR-009).</p> </div> <div class="card gate"> <h3>approvals.py — human-in-the-loop gate</h3> <p>High-risk actions are gated mechanically, not by prompt instruction. A tool name listed in <code>approval_required</code> pauses for a human decision at the tool-execution layer, the same layer <code>safe_path()</code> lives in.</p> </div> <div class="card"> <h3>SQLite Checkpointer — per-agent memory</h3> <p>One database per agent, scoped by <code>thread_id</code>, deliberately kept out of the sandbox root a model's own file tools can reach — a model can't read another thread's history or corrupt its own checkpoint state through <code>write_file</code>.</p> </div> <div class="card"> <h3>Pluggable Tool Library</h3> <p>File I/O, logging, web search, weather, TTS, and digest generation — all least-privilege, all declaring exactly the inputs they need, nothing reaching outside its sandbox by default.</p> </div> <div class="card"> <h3>events.py — WebSocket broadcaster</h3> <p>Lazy-started: if nothing's listening, it's a no-op — zero cost, zero coupling. Every model and tool call broadcasts a telemetry event when something is.</p> </div> <div class="card model"> <h3>Model Backend</h3> <p><code>spec.backend</code> selects <code>"anthropic"</code> (cloud, default) or <code>"local"</code> (any OpenAI-compatible local server, e.g. LM Studio). Only <code>_build_model()</code> branches on this — graph, tools, memory, and telemetry are identical either way.</p> </div> <div class="card viz"> <h3>Live Visualizer (Godot 4)</h3> <p>A 2D top-down scene, fed live over WebSocket, where the agent walks to the station for whichever tool it's calling and shows a speech bubble with what it's doing — the same telemetry a production on-call dashboard would show, just legible at a glance instead of buried in logs.</p> </div> </div> <footer> Source: <a href="https://github.com/COSMOAGNOSTIC/cosmoai-adept" style="color:var(--dim)">github.com/COSMOAGNOSTIC/cosmoai-adept</a> — MIT licensed.
